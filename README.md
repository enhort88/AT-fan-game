# Ууу: Потерянные страницы

Небольшой неофициальный фанатский point-and-click квест по мотивам Adventure Time.

## Что уже есть

- 9 локаций.
- Около 30 персонажей.
- Диалоги и подсказки.
- Инвентарь и простые цепочки предметов.
- 8 основных заданий.
- 8 мини-игр:
  - память БиМО;
  - лаборатория Бубльгум;
  - музыкальная последовательность Марселин;
  - поиск Гюнтера;
  - сортировка Лемонграба;
  - стабилизация огня;
  - лабиринт Джейка;
  - безопасная формулировка желания Призмо.
- Автосохранение в localStorage браузера.
- Адаптация под телефон/планшет/ПК.
- Docker + nginx для сервера.

## Запуск локально

Самый простой вариант:

```bash
cd web
python3 -m http.server 8000
```

Открыть:

```text
http://localhost:8000
```

Можно также просто открыть `web/index.html`, но HTTP-сервер удобнее.

## Запуск через Docker

```bash
docker compose up -d --build
```

Игра будет на:

```text
http://SERVER_IP:8088
```

Остановить:

```bash
docker compose down
```

Посмотреть лог:

```bash
docker compose logs -f
```

## Где менять игру

- `web/index.html` — оболочка.
- `web/styles.css` — внешний вид.
- `web/game.js` — сцены, персонажи, диалоги, предметы, задания и мини-игры.
- `web/assets/` — сюда можно положить настоящие PNG/WebP персонажей и фоны.

Текущая версия специально не зависит от React/Vue/Node на сервере. Это обычный HTML/CSS/JS.

## Следующий очевидный шаг

Заменить цветные круглые аватары персонажей и emoji-декорации на нарисованные PNG/WebP ассеты. Архитектуру менять для этого не потребуется.

Это неофициальный фанатский прототип. Adventure Time и связанные персонажи принадлежат соответствующим правообладателям. Не воспринимать проект как лицензированный продукт.
